# ☸️ 禪-TRIS (Zen-Tris)

**Digital Samsara Simulator** — 블록을 쌓는 것은 고통이요, 비우는 것이 곧 깨달음이라.

전통적인 테트리스에 불교의 '공(空)' 사상과 '윤회' 세계관을 결합한 디지털 수행 시뮬레이터.

## 핵심 시스템

- **업보 (Karma)** — 블록 배치마다 4% 증가, 줄 제거 시 12% 감소. 85% 초과 시 화면 왜곡 발생
- **공덕 (Merit)** — 줄 제거 시 108점 획득. 누적 108줄 제거로 성불(게임 승리)
- **윤회 (Samsara)** — 게임 오버 시 최대 3회 환생. 업보 50%를 이어받고 하단 5줄만 남긴 채 재시작
- **사천왕 (Four Heavenly Kings)** — 4줄 동시 제거 시 사천왕이 강림하여 특수 능력 발동
- **자비의 손길 (Mercy)** — 공덕 300 소모로 하단 1줄 강제 제거

## 조작법

| 키 | 기능 | 설명 |
|---|---|---|
| `← / →` | 이동 | 좌우로 번뇌의 위치를 조정 |
| `↑` | 회전 | 고정된 관념을 바꿈 |
| `↓` | 빠른 하강 | 고통에 정면으로 마주함 |
| `Space` | 자비의 손길 | 공덕을 소모해 바닥을 비움 |

## 기술 스택

- **Runtime:** React 19 + TypeScript
- **Build:** Vite 6
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 디자인 철학

이 게임은 단순한 고득점 경쟁이 목표가 아닙니다.
때로는 비우기 위해 채워야 하고, 죽음(윤회)조차 과정의 일부임을 받아들이는 '디지털 참선'의 경험을 제공하고자 합니다.

> "성불하십시오." 🙏
